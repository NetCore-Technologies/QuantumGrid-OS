AW1000 IMAGE FORMATS

Two firmware images. One recovery image.

01 / FIRST INSTALL

Factory UBI image

*-arcadyan_aw1000-squashfs-factory.ubi

Use with the guarded AW1000 initramfs installer for initial installation and recovery on the supported standard MTD layout.

02 / IN-SERVICE UPDATE

Sysupgrade archive

*-arcadyan_aw1000-squashfs-sysupgrade.bin

For an already-running compatible OpenWrt/QuantumGrid AW1000 system. Verify it and run sysupgrade test mode before updating; not for stock firmware.

03 / TEMPORARY RECOVERY

Initramfs image

*-arcadyan_aw1000-initramfs-uImage.itb

Temporary RAM boot for supported U-Boot/UART recovery and development. It does not write persistent flash by itself.

INTEGRITY FIRST

Verify before you flash.

SHA-256 detects transfer corruption. The host-side verifier also requires GitHub/Sigstore SLSA provenance from the exact pushed qg-v release tag, the pinned firmware workflow, and a GitHub-hosted runner. Use GitHub CLI 2.102.0 or newer; manual-build artifacts are not accepted as releases.

sha256sum -c SHA256SUMS

sh verify-aw1000-release-attestation.sh \
  QuantumGrid-OS-<version>-AW1000-squashfs-factory.ubi SHA256SUMS
AW1000 installation route

QuantumGrid publishes a factory UBI image for first installation, a sysupgrade archive for compatible in-service updates and an initramfs recovery image. The sysupgrade archive is verified for its AW1000 board metadata and must pass OpenWrt test mode before use; it is not accepted by stock/vendor firmware. The UBI route remains a separate, guarded initial-install path: inspect board identity and MTD layout, boot the matching initramfs over UART/TFTP, run the on-router installer in dry-run mode, and proceed only on the documented standard layout. Read the complete recovery and installation guide before changing flash.

No desktop installers.

QuantumGrid OS is router firmware, not a macOS or Windows application. Its release assets are router images and package archives — not DMG, EXE or MSI installers.
