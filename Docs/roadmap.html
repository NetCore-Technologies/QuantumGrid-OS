ROADMAP / WHAT'S NEXT

Build it right.
Prove every layer.

Deliverables move forward when the service exists, the UI is connected and behaviour has been checked on supported hardware.

01 / FOUNDATION · INTEGRATED

AW1000 platform base

OpenWrt target, existing QuantumGrid React control centre, hardware-specific build configuration and first-boot flow.

02 / VOICE · SOURCE INTEGRATED

RJ11 / FXS phone support

Upstream kernel driver, fxsd daemon, LuCI management page and setup guidance. Matching kernel and user-provided Skyworks patch required; hardware validation remains separate.

03 / NETWORK · PARTIALLY INTEGRATED

Real service-backed telemetry

Live system metrics, WAN interface counters, wireless radio state, iwinfo radio channel/frequency lists with restricted flags, regulatory country, supported 802.11 PHY generations and channel widths, current channel centers, driver-supported transmit-power levels (cached for 60 seconds), AP signal/noise, bitrate and transmit-power telemetry, iwinfo-associated Wi-Fi stations, DHCPv4 lease inventory and modem/FXS status are integrated. Per-station signal/noise (average and current), RX/TX rates, HT/VHT/HE/EHT PHY, MCS, spatial streams, channel width, guard-interval metadata, byte/packet counters, inactivity, connection time and transmission retries/failures are shown when the driver exposes them. Per-station RX/TX throughput is derived from successive byte-counter samples; it is not inferred from WAN throughput. The station list sorts negotiated PHY rates independently from measured RX/TX throughput. The associated-client inventory summarises associated/authorized counts and measured throughput sample coverage, and supports local search, band and authorized/associated filtering, independent PHY/measured-throughput sorting and station-diagnostics CSV export with timestamp and applied-filter metadata. QMI registration, serving radio interface, roaming, data-session status and modem RF readings are displayed where returned; up to 30 distinct RF samples are retained in the current UI session without synthetic scores. Current-channel busy airtime is estimated from iwinfo survey counter deltas where supported. A user-triggered iwinfo scan lists nearby access points with SSID/BSSID, band, channel, frequency, driver-reported signal/quality, encryption metadata, cipher suites and HT/VHT/HE/EHT operation width/center-channel information; missing security data remains Unknown. Results are rate-limited and cached. The UI groups observed BSSIDs by reported band/channel and surfaces strongest reported signal, but does not infer airtime or interference from scan counts. Scan inventories can be searched by SSID/BSSID/radio, band, channel, security or mode; filtered by band/security with reset, sorted locally, and exported using the visible result set plus scan time and applied-filter metadata to a spreadsheet-safe CSV and compared across the last ten distinct manual scans in the current UI session, with CSV export and a clear-history action. Persistent client history, automated channel recommendations and roaming/steering remain in development.

04 / PERFORMANCE · PARTIALLY INTEGRATED

Gaming & intelligent QoS

The firmware includes SQM/CAKE packages and QuantumGrid reports configured queue rates plus runtime kernel qdisc statistics. Policy write controls, traffic classification, per-client prioritisation and measured bufferbloat/latency tests remain planned.

05 / WIRELESS · PLANNED

Wi-Fi intelligence & roaming

Radio diagnostics, channel analysis, client steering and DAWN integration with safe rollback.

06 / ACCELERATION · RESEARCH

NSS / EDMA / PPE

Evaluate compatible kernel and driver trees; enable acceleration only after stability, benchmarks and recovery are demonstrated.
