AW1000 IMAGE FORMATS

One persistent image. One RAM-boot image.

01 / PERSISTENT FIRMWARE

Factory UBI image

*-arcadyan_aw1000-squashfs-factory.ubi

The AW1000 persistent firmware artifact. Use only with the verified AW1000-specific installation and recovery instructions.

02 / TEMPORARY RECOVERY

Initramfs image

*-arcadyan_aw1000-initramfs-uImage.itb

Temporary RAM boot for supported U-Boot/UART recovery and development. It does not write persistent flash by itself.

FORMAT NOTE

No sysupgrade image

QuantumGrid does not publish a sysupgrade.bin for this AW1000 profile. Never upload the factory UBI image to a generic sysupgrade form.

INTEGRITY FIRST

Verify before you flash.

SHA-256 detects transfer corruption. A signed GitHub build attestation verifies the downloaded asset against QuantumGrid’s firmware workflow and source provenance.

sha256sum -c SHA256SUMS

gh attestation verify QuantumGrid-OS-<version>-AW1000-squashfs-factory.ubi \
  --repo NetCore-Technologies/QuantumGrid-OS \
  --signer-workflow NetCore-Technologies/QuantumGrid-OS/.github/workflows/firmware-release.yml
AW1000 installation route

QuantumGrid publishes a factory UBI image, a temporary initramfs image, SHA256SUMS, a read-only AW1000 target inspector, a release-manifest verifier and a conservative on-router installer. First run the inspector on the currently installed router to record board identity and MTD layout. Then boot the matching initramfs over UART/TFTP, transfer the image, manifest and installer scripts together, and run the installer in dry-run mode. It verifies the exact image digest, accepts only the original standard 100 MiB AW1000 MTD layout and requires explicit console confirmation before writing rootfs. Expanded layouts are refused. Read the complete recovery and installation guide before flashing.

No desktop installers.

QuantumGrid OS is router firmware, not a macOS or Windows application. Its release assets are router images and package archives — not DMG, EXE or MSI installers.
