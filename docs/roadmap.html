ROADMAP / WHAT'S NEXT

Build it right.
Prove every layer.

Deliverables move forward when the service exists, the UI is connected and behaviour has been checked on supported hardware.

01 / FOUNDATION · INTEGRATED

AW1000 platform base

OpenWrt target, existing QuantumGrid React control centre, hardware-specific build configuration and first-boot flow. The release pipeline packages a device-specific factory UBI image, temporary initramfs, build provenance and checksums; a guarded on-router installer preflights the original standard AW1000 MTD layout and refuses expanded or unknown layouts.

02 / VOICE · SOURCE INTEGRATED

RJ11 / FXS phone support

Upstream kernel driver, fxsd daemon, LuCI management page and setup guidance. Matching kernel and user-provided Skyworks patch required; hardware validation remains separate.

03 / NETWORK · PARTIALLY INTEGRATED

Real service-backed telemetry

Live system metrics, WAN interface byte/packet/error/drop counters from sysfs with scope filtering, support CSV export including successive-sample deltas, wireless radio state, iwinfo radio channel/frequency lists with restricted flags, regulatory country, supported 802.11 PHY generations and channel widths, current channel centers, driver-supported transmit-power levels (cached for 60 seconds), AP signal/noise, bitrate and transmit-power telemetry, iwinfo-associated Wi-Fi stations, searchable/sortable DHCPv4 lease inventory with filtered CSV export and modem/FXS status are integrated. The Security Center also exports read-only firewall zones, nftables table presence, DNS-filter configuration and VPN service/interface status without keys or credentials. The Security Center also performs a read-only posture review of the firewall service, config readability, fw4 runtime table and standard WAN/WWAN zone input/forward defaults. ACCEPT defaults are flagged for manual review; missing telemetry and custom zone naming remain explicitly unknown rather than being labelled secure. The Security Center also lists up to 64 redacted UCI rule summaries (zone direction, protocol, target, ports and address-match presence) with local search/sort and CSV export; enabled ACCEPT rules sourced from WAN/WWAN-like or unrestricted source zones are flagged for review. Raw IP/MAC values and packet-path conclusions are not returned. Per-station signal/noise (average and current), RX/TX rates, HT/VHT/HE/EHT PHY, MCS, spatial streams, channel width, guard-interval metadata, byte/packet counters, inactivity, connection time and transmission retries/failures are shown when the driver exposes them. Per-station RX/TX throughput is derived from successive byte-counter samples; it is not inferred from WAN throughput. The station list sorts negotiated PHY rates independently from measured RX/TX throughput. The associated-client inventory summarises associated/authorized counts and measured throughput sample coverage, and supports local search, band and authorized/associated filtering, independent PHY/measured-throughput sorting and station-diagnostics CSV export with timestamp and applied-filter metadata. QMI registration, serving radio interface, roaming, data-session status and modem RF readings are displayed where returned; up to 30 distinct RF samples are retained in the current UI session without synthetic scores and can be exported as CSV with per-reading UTC timestamps. Current-channel busy airtime is estimated from iwinfo survey counter deltas where supported. A user-triggered iwinfo scan lists nearby access points with SSID/BSSID, band, channel, frequency, driver-reported signal/quality, encryption metadata, cipher suites and HT/VHT/HE/EHT operation width/center-channel information; missing security data remains Unknown. Results are rate-limited and cached. The UI groups observed BSSIDs by reported band/channel and surfaces strongest reported signal, but does not infer airtime or interference from scan counts. Scan inventories can be searched by SSID/BSSID/radio, band, channel, security or mode; filtered by band/security with reset, sorted locally, and exported using the visible result set plus scan time and applied-filter metadata to a spreadsheet-safe CSV and compared across the last ten distinct manual scans in the current UI session. Comparison identifies newly observed and no-longer-observed BSSIDs and ranks numeric signal changes for matching BSSIDs; missing observations are not interpreted as offline access points. Only the minimal network identifiers and signal fields needed for comparison are retained in page memory, with no browser-storage persistence. The comparison exports spreadsheet-safe CSV and the scan history has a clear-history action. Associated- client inventory also filters and sorts by driver-reported TX retries/failures; these are cumulative counters, not packet-loss scores. The Network page also inventories IPv4/IPv6 default routes and policy-routing rules, including lookup tables, priorities, firewall marks and interface selectors. A coverage view cross-references lookup tables with default routes, while keeping missing defaults distinct from invalid or unused policy. These are read-only kernel snapshots, not packet-path simulation or Multi-WAN health verification. The Advanced page also reports firmware/board identity, loaded kernel modules, service-script and diagnostic-tool presence, MTD partitions, block devices and important system mounts, including filesystem capacity/available space when statvfs is supported, through read-only checks. The Advanced page also surfaces a live uptime, CPU, memory, temperature and load-average snapshot, included in its spreadsheet-safe support CSV export. An on-demand five-packet ICMP test is integrated in Diagnostics with packet-loss percentage, RTT min/average/max and mean absolute consecutive-RTT variation (jitter). It uses a fixed target, same-origin administrator request and 30-second cache; it does not claim a controlled-load bufferbloat result. Opt-in, browser-local Wi-Fi client history is also available: an administrator can manually save snapshots of currently associated stations, retain 1, 7 or 30 days (up to 10,000 observations), export CSV and clear the history. It is disabled by default, stores MAC addresses and available DHCP hostname/IP details only in that browser's local storage, and is not uploaded, encrypted or synced. A snapshot is written only after the explicit Save snapshot action; it is not an automatic monitor. Automatic capture, automated channel switching, client steering and roaming remain in development.

04 / PERFORMANCE · PARTIALLY INTEGRATED

Gaming & intelligent QoS

The firmware includes SQM/CAKE packages and QuantumGrid reports configured queue rates plus runtime kernel qdisc statistics, which can be searched and sorted by byte, drop and backlog counters, then exported with the active filters for support review. The Gaming page can now edit the enabled flag and upload/download rates of existing SQM queue sections only; the authenticated API validates section names and 64–1,000,000 kbit/s limits, commits the three fixed options and restarts SQM. If restart fails, it attempts to restore the previous values, including previously absent options. Diagnostics also includes the bounded five-packet latency/loss/jitter sample. CAKE tuning, traffic classification, per-client prioritisation and controlled-load bufferbloat tests remain planned.

05 / WIRELESS · PARTIALLY INTEGRATED

Wi-Fi intelligence & roaming

Radio diagnostics, scan-to-scan comparison and a read-only supported-channel shortlist weighted by observed BSSID signal and channel-width overlap are integrated. Channel writes, automated channel switching, client steering and DAWN integration with safe rollback remain planned.

06 / ACCELERATION · RESEARCH

NSS / EDMA / PPE

Evaluate compatible kernel and driver trees; enable acceleration only after stability, benchmarks and recovery are demonstrated.

Roadmap integrity.

Planned items are not shipped features. The roadmap will be updated as implementations, test results and supported device combinations are verified.
